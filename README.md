# 学术写作Skill包

本目录包含三类互补能力：1号用于通用、批量的学术语言润色；2号用于提炼导师稳定的写作风格；3号是个人润色Skill，可自由补充和修改。

## 1号Skill：通用学术写作语言润色

使用前，先填写`1_Academic_Writing_Skill/TASK_REQUEST_TEMPLATE.md`中的任务信息并将完整模板交给AI，或者使用以下简化提示词直接进行润色：

```text
请完整读取 1_Academic_Writing_Skill/SKILL.md 及其引用的全部规则，对 <输入文件或目录> 进行学术语言润色。

输出方式：直接返回润色后的文本，或保存为新的.tex、.md或.txt文件。处理目录时，将新文件保存到 <输出目录> 并保持原有目录结构，不覆盖原文件。

要求：不改变论点、引用、数值、公式和专业术语。只有我明确要求时才生成POLISHING_REPORT.md。
```

> 来源：https://github.com/Imbad0202/academic-research-skills

## 2号Skill：导师写作风格语言润色

构建流程：

1. 下载导师10篇第一作者或由导师主笔的顶级论文，放入同一目录。
2. 让Codex或Claude Code完整阅读这些论文，并使用以下提示词提炼风格：

```text
请完整阅读<导师论文目录>中的10篇论文，用英文提炼导师跨论文稳定出现的学术写作风格。

重点分析：
1. 论文整体论证逻辑，以及问题、研究缺口、方法和证据之间的连接方式；
2. 摘要、引言、相关工作、方法、实验和结论的组织顺序；
3. 段落功能、主题句位置、句间信息推进和章节转折方式；
4. 常用词汇、固定搭配、报告动词、转折表达和术语复现方式；
5. 句长、段落长度、主动或被动语态、模糊限制语和引用嵌入方式；
6. 经常避免的表达及其替代方式。

只保留跨多篇论文稳定出现的特点，区分导师个人偏好与学科通用规范，不复制论文原句，不虚构未观察到的风格。最后将结果导出为可直接使用的Skill文件，写清适用范围、核心写作逻辑、各部分写法、词汇特点、润色规则、禁止修改的内容和使用方式。
```

使用方式：

```text
请完整读取 <导师Skill文件>，按照其中的写作风格优化下面的论文内容。保持原意、事实、引用、数值、公式和专业术语不变。

<待优化内容>
```

## 3号Skill：个人写作风格语言润色

建议使用方式：每次先读取Skill文件，再只优化一个段落，确认结果后继续下一段，避免错误累积。

```text
请完整读取 3_my_writing_skill.md，然后只优化下面一个段落。提高逻辑性、连贯性、准确性和学术表达质量，但不要改变原意、引用、数值、公式和专业术语。

<待优化段落>
```
